# 视频保存到手机与有线传到电脑

适用于 iOS App **0.2.8（build 10）**。不需要训练电脑在线，不需要先完成局域网上传。

## 保存已拍视频

1. 打开「我的项目」→ 对应项目 → 对应采集批次。
2. 在「保存视频到手机」区域选择：
   - **保存到相册**：复制本批次全部视频到系统「照片」。首次使用允许 App **添加照片**；不要求读取相册。保存完成后显示实际成功数量。
   - **导出到文件**：系统窗口默认打开 App 的本机「视频导出」文件夹，点击「存储」完成复制。也可以选择「我的 iPhone」下的其他文件夹。选择 iCloud 云盘会使用云存储，若要离线本地保存，请选择本机位置。
3. 若只需要某一段视频，点击该素材进入「视频预览」，使用底部同样的两个按钮。

两个入口都复制原始 MOV 文件，不重新编码、不改变 4K / 1080p 分辨率，不删除 App 内的视频或项目记录。取消或保存失败也不会清理原件。相册逐个保存，若部分失败会显示已经成功的数量；再次保存会新增副本。

大视频保存时保持 App 前台。相册未授权时，可通过「打开系统设置」允许添加照片，或直接使用「导出到文件」。空间不足或文件不可读时显示实际错误，不会显示成功。

## 用数据线取到训练电脑

- **相册路径**：保存完成后，连接并解锁 iPhone、信任电脑，用 Windows 的照片/视频导入功能或 Mac 的「图像捕捉」导入视频。
- **App 文件共享路径**：在「导出到文件」窗口使用默认本机「视频导出」目录保存后，连接并解锁 iPhone。在 Mac Finder 的设备「文件」区域，或 Windows「Apple 设备」应用的设备「文件」区域，找到「3DGSMAP 采集」并复制导出文件夹到电脑。只有 Documents 中的导出副本对文件共享开放；原始采集视频和项目索引仍位于 App 私有 Application Support 目录。

如果保存到了其他 App 的本机文件夹，需通过那个 App 的文件共享或系统分享功能取出，不会出现在 3DGSMAP 的文件共享目录。

电脑收到原始视频后，按训练电脑现有的本地视频导入/抽帧流程创建任务；本功能只负责复制视频，不自动提交训练任务。

## 更新时保留原件

使用原来的签名 Team 和 Bundle Identifier **覆盖安装**，不要卸载 App。源码压缩包已同步到 0.2.8；现有 0.2.7 上传改进也保留。
